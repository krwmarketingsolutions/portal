📋 How to Add a New Campaign
Follow these steps every time. Takes under 5 minutes.
1
Get the spec file from Claude
Paste the buyer's posting instructions into Claude and ask for a campaign spec file. Takes 30 seconds.
2
Run the INSERT SQL in Railway
Go to Railway → Postgres → Database → Data → Query box. Use the template below. Always include ::jsonb after each array.
3
Add LP credentials to server.js
Open server.js on GitHub. Find LP_CREDS and add one line for the new campaign. Push to GitHub → Railway redeploys in 60s.
4
Test — visit the form URL
Open krwmarketingsolutions.github.io/forms?campaign=SLUG&sub=TEST — if the form loads with correct fields, you're done.
🗄 SQL Templates — Copy & Paste into Railway
Use these exact templates. Replace values in CAPS.
INSERT new LeadProsper campaign 
INSERT INTO campaigns (slug, name, vertical, apex_endpoint, required_fields, optional_fields, field_labels, active)
VALUES (
  'SLUG',
  'Campaign Name',
  'Vertical Type',
  'https://api.leadprosper.io/direct_post',
  '["firstName","lastName","email","phone","REQUIRED_FIELD_1","REQUIRED_FIELD_2"]'::jsonb,
  '["dateOfBirth","gender","street","city","state","jornayaLeadId","publisherSub","tcpaText"]'::jsonb,
  '{}'::jsonb,
  true
)
ON CONFLICT (slug) DO UPDATE SET
  required_fields = EXCLUDED.required_fields,
  optional_fields = EXCLUDED.optional_fields,
  apex_endpoint   = EXCLUDED.apex_endpoint,
  active = true;
UPDATE existing campaign fields 
UPDATE campaigns SET
  required_fields = '["firstName","lastName","email","phone","FIELD_1","FIELD_2"]'::jsonb,
  optional_fields = '["dateOfBirth","gender","state","zip","publisherSub"]'::jsonb
WHERE slug = 'SLUG';

-- Verify it saved:
SELECT required_fields FROM campaigns WHERE slug = 'SLUG';
Add LP credentials to server.js 
// In server.js, find LP_CREDS and add:
'SLUG': { id: 'LP_CAMPAIGN_ID', sup: 'LP_SUPPLIER_ID', key: 'LP_KEY' },
